# Local TOML Schemas Management Guide

[← Back to Wiki Index](index.md)

This guide explains how offline, 100% local TOML schema validation and autocompletion are configured in Neovim using the `taplo` LSP server and local schema files stored in `schemas/toml/`.

## 🧠 How Taplo TOML Schema Association Works

In [`lua/plugins/lsp/lsp.lua`](../lua/plugins/lsp/lsp.lua), Taplo is configured using the `even_better_toml.schema` table:

```lua
opts.servers.taplo.settings = {
    even_better_toml = {
        schema = {
            enabled = true,
            repository = false, -- Disables fetching remote schema repositories (100% offline)
            associations = {
                ["^bunfig\\.toml$"] = get_schema_uri("toml", "bunfig.json"),
            },
        },
    },
}
```

### Property Key Breakdown:
1. `enabled = true`: Enables schema validation and autocomplete in Taplo.
2. `repository = false`: **Disables online repository fetching**. Forces Taplo to strictly rely on local schemas defined in `associations`.
3. `associations`: A Lua table mapping **Lua regular expression patterns** to local file URIs generated by `get_schema_uri("toml", "filename.json")`.

## 📝 TODO Checklist: How to Add a New TOML Schema

Follow this step-by-step checklist whenever you want to add a new TOML schema validation.

- [ ] **Step 1: Obtain the JSON schema for your TOML tool**
  Save the schema `.json` file inside `schemas/toml/`.  
  *Example file path:* `C:\Users\Kristan\AppData\Local\nvim\schemas\toml\cargo.json`

- [ ] **Step 2: Open [`lua/plugins/lsp/lsp.lua`](../lua/plugins/lsp/lsp.lua)**
  Locate `opts.servers.taplo.settings`.

- [ ] **Step 3: Add a new entry to `associations`**
  Map the filename regex pattern to your local schema file URI using `get_schema_uri("toml", "your-file.json")`:

  ```lua
  associations = {
      ["^bunfig\\.toml$"] = get_schema_uri("toml", "bunfig.json"),
      ["^Cargo\\.toml$"] = get_schema_uri("toml", "cargo.json"), -- <-- Added here
      ["^pyproject\\.toml$"] = get_schema_uri("toml", "pyproject.json"), -- <-- Example 2
  },
  ```

  *Note on Regex Patterns:* Remember to escape dots in filenames with double backslashes (`\\.`). For example, `pyproject\\.toml$` matches `pyproject.toml`.

- [ ] **Step 4: Restart Neovim or run `:ReloadConfig`**

- [ ] **Step 5: Verify Taplo Validation**
  1. Open a target TOML file (e.g. `bunfig.toml` or `Cargo.toml`).
  2. Run `:LspInfo` to verify `taplo` is active on the buffer.
  3. Start typing in the TOML file to verify autocompletion and diagnostic warnings.
